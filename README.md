## Try a solution

Open a file such as [Vowel Balance](./August/Vowel%20Balance) or [Flatten the Array](./January/Flatten%20the%20Array). Copy the Python code below the title into the challenge editor to run freeCodeCamp's tests. To experiment locally, paste the code into a `.py` file and add a function call with your own test input.
